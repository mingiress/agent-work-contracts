## Updates

Update the upstream only through a reviewed change that records the new commit, copies the entire upstream skill subtree, preserves its copyright/license, and regenerates the manifest after checking the actual source. Never silently patch the vendored copy while retaining old hashes. Companion updates must state their changed behavior and actual verification; no automatic pull from a user's running skill library.
